# Игра «Найди улики» 
### ***[Запустить](https://d-sromea.github.io/Clues/)***

## Назначение

Интерактивная мини-игра, в которой пользователь должен найти ошибки
или улики на изображении.

Игровое поле содержит изображение и невидимые кликабельные зоны.
При наведении зона подсвечивается красным. После правильного клика
она остаётся отмеченной зелёным цветом, а счётчик найденных улик увеличивается.

## Технологии

- HTML5 — структура страницы и интерактивные кнопки-зоны
- CSS3 — адаптивная вёрстка, подсветка, состояния и анимация
- JavaScript — игровая логика, счётчик, подсказки и сброс

## Игровая механика

1. Скрипт находит все элементы с классом `.clue`.
2. Каждая улика имеет уникальный атрибут `data-id`.
3. При клике id улики добавляется в `Set foundClues`.
4. Найденной зоне добавляется CSS-класс `.found`.
5. Скрипт обновляет счётчик.
6. Когда количество найденных улик равно количеству зон, игрок получает сообщение о завершении уровня.
7. Кнопка «Подсказка» временно выделяет одну случайную не найденную улику.
8. Кнопка «Сбросить» возвращает игру к начальному состоянию.
